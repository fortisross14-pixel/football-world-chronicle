# Real-world historical icons — v0.19

The game remains a fictional universe. Historical names appear as curated career templates inside that universe rather than recreating real chronology.

## Curated database

- Generational: 16 templates
- Legend: 69 templates
- Epic: 120 templates

Each template stores a real name, nationality, position, tactical role, base quality, career type, career length, starting club and fallback starting country.

## Active population rules

The elite population remains partly procedural:

- Generational: exactly 1–2 active real icons among the three simultaneous slots.
- Legend: 5–7 active real icons among approximately fifteen slots.
- Epic: 9–12 active real icons among approximately fifty slots.

When an elite slot opens, the current number of active real icons determines whether the replacement must be real, must be procedural or is decided probabilistically. A historical identity is used only once per universe.

## Starting clubs

A historical icon starts at the curated club when that club exists. When it does not—such as a player associated with an excluded club—the game selects a club in the same country. The icon completes the first visible season at that club before becoming eligible for the standard transfer market.

## Save compatibility

Existing saves are not rewritten. Historical icons begin entering those universes through future rookie generations. New universes receive the controlled real/procedural mix immediately.
